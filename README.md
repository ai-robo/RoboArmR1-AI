# RoboArmR1-AI - робот-манипулятор c компьютерным зрением и голосовым управлением

Проект позволяет управлять роботом-манипулятором **RoboArm R1** с помощью команд на естественном языке. Например: «**Робот, возьми зелёный кубик и положи его в коробку**» или «**Робот, поставь синий кубик на красный**».

Система демонстрирует, как объединить распознавание речи, большую языковую модель и компьютерное зрение для управления физическим роботом. Пользователю не нужно указывать координаты предметов или писать команды для сервоприводов.

## Как это работает

1. С помощью библиотеки **Vosk** происходит преобразование речи в текст. Команда принимается только после ключевого слова «Робот»). Фраза завершается после паузы около 3 секунд или слова «Выполняй».
2. **DeepSeek** определяет, какой кубик взять и куда его положить. Модель возвращает структурированный JSON-план, команды для сервоприводов не формируются.
3. Далее мы проверяем составленный план, наличие кубиков и допустимость перемещений. **OpenCV** находит объекты и рассчитывает их координаты.
4. **RoboArm R1** захватывает и переносит кубик, возвращается в исходное положение и ждёт следующую команду. Изображение с камеры транслируется в реальном времени (почти).

Пока поддерживаются **красный, зелёный и синий** цвета кубиков. Возможные действия: перенос в определенную точку и установка одного кубика на другой.

## Оборудование

- Робот-манипулятор **RoboArm R1** с захватом и подключением к компьютеру по USB/Serial (115200 бод).
- Камера, закреплённая над рабочей поверхностью.
- USB-микрофон, доступный через PortAudio.
- Рабочая поверхность с четырьмя маркерами **ArUco DICT_4X4_50** (ID 0–3) и цветными кубиками 20 × 20 × 20 мм.
- Компьютер с Ubuntu и доступом к интернет для DeepSeek API.

Документация производителя: [RoboArm R1 — команды управления](https://armbrain.ru/articles/roboarm-r1-control-commands). Основные команды протокола: `state`, `go x=... y=... z=...`, `go claw=0` (закрыть захват), `go claw=50` (открыть).

## Калибровка и координаты

Камера видит координаты объектов **в пикселях**, а манипулятор работает **в миллиметрах** в собственной системе координат. Поэтому калибровка выполнена в два этапа:

1. По четырём ArUco-маркерам с известными позициями рассчитана **гомография** `H_pixel_to_board`: она переводит координаты изображения в координаты рабочей поверхности. Результат сохранён в отдельный файл `board_calibration.npz`.
2. Для нескольких контрольных точек сопоставлены координаты на рабочей поверхности и измеренные положения RoboArm. По этим соответствиям рассчитано преобразование `robot_xy = R @ board_xy + t`, сохранённое в отдельный файл `robot_alignment_far_DIAGNOSTIC.npz`.

Таким образом, цепочка выглядит как **пиксели камеры -> миллиметры поверхности -> координаты RoboArm**. Во время работы программа дополнительно проверяет положение маркеров и границы разрешённой зоны. Если камера или маркеры перемещены, калибровку необходимо выполнить заново.

## Установка

Нужны **Python 3** и системная библиотека PortAudio. Например, в Ubuntu:

```bash
sudo apt update
sudo apt install python3-venv libportaudio2
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install numpy opencv-contrib-python pyserial sounddevice vosk openai
```

Скачайте русскоязычную модель с [сайта Vosk](https://alphacephei.com/vosk/models) и распакуйте её в папку `vosk-model-small-ru-0.22/` рядом с программой. В папке проекта должны находиться восемь рабочих `.py`-файлов и два файла калибровки `.npz`.

Задайте ключ DeepSeek API через переменную окружения:

```bash
export DEEPSEEK_API_KEY="ваш_ключ"
```

## Запуск

Сначала проверьте, какой индекс получила звуковая карта в PortAudio:

```bash
python3 roboarm_deepseek_voice.py --list-mics
python3 roboarm_deepseek_voice.py --check-mic --mic-device 6
```

`6` — индекс микрофона в исходной конфигурации; на другом компьютере он может отличаться.

**Проверка без движения робота:**

```bash
python3 roboarm_deepseek_voice.py --camera 0 --mic-device 6
```

**Голосовое управление манипулятором:**

```bash
python3 roboarm_deepseek_voice.py \
  --camera 0 \
  --port /dev/ttyUSB0 \
  --mic-device 6 \
  --execute
```

Произнесите: «**Робот, возьми красный кубик и положи его в точку один. Выполняй**». После завершения робот вернётся в HOME и продолжит ожидать команды. Выход — **Esc**.

> **Безопасность:** параметр `--execute` разрешает физические движения. Перед первым запуском проверьте калибровку, свободное пространство и начальную высоту захвата. Программная остановка не прерывает мгновенно уже отправленное движение — держите доступным отключение питания приводов. Высоту установки кубика на другой кубик следует проверить на конкретном стенде.
